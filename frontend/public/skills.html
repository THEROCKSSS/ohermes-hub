Skills

This whole hub is built from small, self-contained skill files — real instructions grounded in this actual codebase, not generic advice. Grab any of them and drop it into your own Claude Code ~/.claude/skills/ directory (or hand it to any AI coding agent) to build your own copy. Local-only — none of these touch Tailscale, DuckDNS, or a real domain; that's deliberately a separate step once your local copy actually works.

1. Backend / provider

ohermes-hub-backend-provider-setup

A small FastAPI service that reads your curated repo list, enriches it with live GitHub data (stars, license, open issues, commit activity), and serves it as JSON. Covers caching discipline, the fail-soft pattern for flaky GitHub calls, and why the README endpoint has to be allowlisted.

Tested: this is the exact code running behind /api/ on this live hub, plus rebuilt again from scratch as half of the full-stack test below.
2. Frontend webpage

ohermes-hub-frontend-webpage-setup

Plain HTML/CSS/vanilla JS, no framework, no build step — served by nginx, which proxies /api/ to the provider. Covers the one rule that matters most: never render API-sourced content with innerHTML. Also covers the shared nav/footer partial pattern so you're not duplicating navigation across every page.

Tested: browser-verified on this live hub (real DOM checks, not just HTTP status codes) — search, sort, compact view, and the nav all confirmed working in an actual browser session.

The periodic pass for keeping the curated project list current — finding new public repos to add, catching ones that went private or got deleted, and rewriting stale descriptions. Not a cron job; a checklist for when you remember, or just pushed something new.
