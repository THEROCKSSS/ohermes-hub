API docs

Every endpoint this hub exposes — all read-only, all public, no auth. The frontend on this same site is the primary consumer, but nothing stops you hitting these directly.

GET /api/projects

Curated project list enriched with live GitHub data — stars, license, open issues, creation/push dates, and a 13-week commit sparkline. Cached 10 minutes.

GET /api/projects/{repo}/readme

Raw README text (not markdown-rendered) for one curated repo.

GET /api/changelog

Recent commits across every listed repo, newest first. Cached 10 minutes.

GET /api/changelog.rss

The same data as an RSS 2.0 feed.

GET /api/uptime

Live health checks against the self-hosted services this hub sits alongside. Cached 60 seconds.

GET /api/health

Machine-readable status for this hub itself — for external uptime monitors.

GET /api/status

Minimal liveness check.
