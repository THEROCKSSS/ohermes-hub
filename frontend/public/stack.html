What this runs on

The real infrastructure behind this site, with real version numbers. NON-LIVE DATA — static page, updated by hand when the stack changes.

This hub, specifically

FastAPI 0.115.0

Backend framework for the GitHub-data proxy/cache (/api/*).

uvicorn 0.30.6

ASGI server running the FastAPI app.

httpx 0.27.2

Async HTTP client the backend uses to call GitHub's public API.

Python 3.12 (slim)

Backend container base image.

nginx (alpine)

Serves the static frontend and reverse-proxies /api/, /docs, /forgejo/.

Docker Compose

Two containers — hub-frontend and hub-api — no shared runtime.

The wider setup

Caddy

Reverse proxy + TLS for the domains this hub and its siblings sit behind. Real Let's Encrypt certs via DNS-01 (DuckDNS) — see the caddy-dns-duck skill for exactly how.

DuckDNS

Free dynamic DNS for every domain in this setup.

Tailscale

Private mesh networking — most self-hosted projects here are also reachable over a private tailnet, no public exposure required.

Forgejo

Self-hosted Git + issues, used for cross-project work.

Windows + WSL2

Host OS for the Docker Desktop backend running all of this.
