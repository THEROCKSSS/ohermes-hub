Roadmap

High-level direction for this hub — distinct from the per-project Ideas board, which only ever lists things once they're public on GitHub. NON-LIVE DATA — hand-written, updated when things actually change.

Shipped

  • 18 pages + top nav — Now, Blog, Stack, Timeline, Uptime, API Docs, Credits, Press, Tools, Year in Review, Wishlist, Talks, License, Roadmap, Archive, Contact, plus a custom 404.
  • Project grid enhancements — sort, random-project, compact view, per-card commit sparkline, license + open-issues badges, similar-projects cross-links, and a project detail page with the real README.
  • Portable setup skills — four skills on /skills.html so anyone can build their own copy, or keep this one's content current.

Known open issue

  • Movie List's path on this domain (port 8444) is still unpublished — a Docker Desktop host-port binding got stuck during setup and survived every fix attempted (a full backend restart, a network recreate, isolation testing). Not a security issue, just not live yet. Movie List itself is unaffected and reachable through its other paths.

Under consideration

From the same 100-item brainstorm that produced the pages/grid work above — real ideas, not yet built, not yet approved:

  • Changelog — per-project filtering, a contribution heatmap, real pagination.
  • Visual polish — light/dark toggle, a command palette (Cmd/Ctrl+K), skeleton loading states.
  • Data & stats — combined star count in the hero, per-repo dependency counts, aggregate language breakdown.
  • Search & navigation — keyboard shortcuts, URL-persisted filters, fuzzy search.
  • Content & writing — per-project "why I built this" blurbs, more blog posts.
  • Integrations — Forgejo activity merged into the changelog, a real uptime-monitor backend instead of the hand-rolled health checks.
  • Accessibility — full keyboard-nav audit, `prefers-reduced-motion` support, screen-reader landmark regions.
